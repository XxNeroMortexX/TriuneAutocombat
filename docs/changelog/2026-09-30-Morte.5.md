# Triune 3.1-Morte.5 — September 30, 2026

NeroMorte's cumulative September 30 update, based on Gennro TAC 3.1. The MQ2WebUpdate engine remains 4.1.6. Earlier AA spending controls remain included; this update adds the changes below.

## Pet camp combat and pulling

- **Pets Pull - Player Stay in Camp** in Puller → Camp → Pet lets pets fight eligible mobs in Pull Radius while the player stays at camp.
- **Player Assist Radius** replaces the displayed Engagement Distance while that option is enabled. Player assistance uses this radius or a direct threat to the character; actual melee/spell ranges still apply.
- Optional **Pet Pull Back to Camp** gathers a batch using **Mobs per Pull**. It recalls a smaller batch when no eligible next mob remains and stops gathering when the fight reaches the player.
- Prefer a living pet with confirmed Taunt ON for pulling. If all living pets are confirmed Taunt OFF, send all pets; unknown states are not treated as OFF.
- Far-distance pet dispatch uses pet assist plus owner attack. Owner attack is turned OFF before recall so automatic assistance does not immediately send pets back out.
- Wait for the exact selected mob ID to appear on hostile XTargets before counting the pull or moving to another mob.
- **Pet Recall Delay (seconds)** is saved beside the pull-back controls: default 5 seconds, minimum 0. The timer starts after the pulling pet reaches camp. A nearby mob inside Player Assist Radius or a direct threat permits earlier engagement; otherwise pets resume nearby cleanup after the delay.
- Returned pets can finish nearby enemies just outside Player Assist Radius while player assistance continues to respect its own radius.
- Finish existing hostile XTargets before starting a fresh pull. This also fixes ordinary Camp/Hunt puller paths; Hunt's explicit Ignore Distant XTargets option remains respected.
- Non-returning pet combat can select the next eligible mob after the current fight ends without waiting for pets to return to the player.

## Pet window states

- Pet stance/toggle buttons show known current states with pressed styling and highlighted text.
- Resolve pet names/classes before dispatch so the correct class receives commands.
- Cache states by pet ID and update them from matching Pet-window data and recognized pet messages.
- Capture states at startup/new-pet discovery when safely idle, or use Refresh Pet States. Feign death, movement, casting, and combat defer capture; stand up safely to allow it.
- Restore the previous target after capture unless the player changed it. Death, zoning, or character changes invalidate stale pet data.
- Unknown/unsupported states remain unknown rather than displaying invented values. Routine combat does not repeatedly target each pet for snapshots.

## Tell and guild commands

- Optional group **invite** and expedition **dzadd** commands are available in Auto-Accept settings.
- Tells: `invite`, `invite me`, or `invite PlayerName`; likewise `dzadd`, `dzadd me`, or `dzadd PlayerName`. Blank or `me` means the sender.
- Guild commands must start with the bot's character name, for example `Mortefreddo invite me` or `Mortefreddo dzadd PlayerName`.
- Commands use the configured sender permissions and cooldown; these controls default OFF.
- An authorized DZ request gets a private “I'm not in a DZ” response when the bot can confirm it is not in an expedition.

## Ranges, targeting, and maps

- Camp Radius, Pull Radius, Search Radius, and Engagement Distance sliders now start with a 10,000-unit drag range and expand for larger saved/typed values. Ctrl-click numeric entry remains available; these settings no longer impose the old upper gameplay limits.
- Auto AA Bank minimum is back to **1**.
- Beneficial spells whose actual TargetType is **Self** cast without switching to the player or pet. Spells that genuinely require a target keep their targeting behavior; AA/clicky targeting is unchanged.
- Native EverQuest/MQ2Map again shows a camp X and radius circle, controlled by **Show Camp on EQ Map**.
- Clear Camp removes its marker; automatic camp recreation redraws it. The feign/stand camp refresh path is fixed.
- Radius dragging coalesces redraws briefly and performs an exact final redraw when editing ends.

## Quieter output and fixes

- Routine `Issued: #petcmd` messages are now Debug-only.
- **Suppress Auto AA purchase/skip messages** in Settings → General optionally silences routine AA messages. It defaults unchecked; errors and explicitly requested status remain visible.
- Fixed the Control-window crash caused by passing ImGui InputInt's changed flag into `math.max`.
- Original Gennro edit blocks retain **Edited By: NeroMorte** markers; new support code is separately identified.
